# Gallery images

Add personal, event, research, or extracurricular photos to this folder.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, and `.avif`.

Use descriptive filenames because they become the default captions, for example:

- `research-showcase-2026.jpg`
- `uqcs-industry-night.jpg`
- `bodyboarding-gold-coast.jpg`

After adding images, restart the development server.
